# SUDOKU∞ — Train Your Mind Daily

##  О проекте
SUDOKU∞ — это современная веб-платформа для игры в Судоку, созданная как полноценный продукт, а не просто игра.

##  Для кого это
Для людей которые хотят тренировать мозг ежедневно — студенты, профессионалы, все кто любит логические игры.

##  Функционал
- Генератор уникальных головоломок (Easy / Medium / Hard / Expert)
-  Таймер, подсказки, заметки в ячейках, отмена хода
-  Daily Challenge — ежедневное испытание
-  AI Coach — объясняет стратегии решения
-  Глобальный лидерборд + рейтинг городов
- Личная статистика и графики
-  Тёмная и светлая тема
- ✦ Pro версия с расширенными функциями

##  Идея
Судоку — это не просто игра. Это ежедневная тренировка мозга. SUDOKU∞ делает этот процесс красивым, социальным и мотивирующим.
