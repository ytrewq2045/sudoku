# ZENKU — Premium AI-Powered Sudoku 

**ZENKU** — это не просто еще одна игра в судоку. Это премиальная веб-платформа для тренировки мозга, объединяющая классическую логику с возможностями искусственного интеллекта и современным бизнес-подходом.

🔗 [(https://ytrewq2045.github.io/sudoku/))

---

##  Проблема и Решение
**Проблема:** Существующие сайты для Судоку выглядят как привет из 2005 года: они перегружены рекламой, имеют плохой UX на мобильных устройствах и никак не помогают новичкам учиться (дают либо решение целиком, либо ничего).
**Решение:** ZENKU предлагает минималистичный, "zen" интерфейс без лишнего шума, где главным помощником выступает **AI Coach**. Он не решает пазл за пользователя, а объясняет логику и учит стратегиям (Cross-Hatching, Hidden Singles и т.д.).

---

##  Ключевые фичи (Что выделяет продукт на рынке)

*   **🧠 AI Coach (Умный наставник):** Анализирует текущее состояние доски и дает контекстные подсказки. Умеет объяснять стратегию и указывать на логические ошибки. *(В данном MVP реализован через умные моки на фронтенде для демонстрации UX без затрат на API).*
*   **💎 Premium UX/UI:** Адаптивный дизайн, стеклянный морфизм (glassmorphism), выверенная типографика и плавные анимации. Играть приятно как с ПК, так и с телефона.
*   **🌍 Daily Challenge (Продуктовый хук):** Концепт ежедневных испытаний для глобального лидерборда. Заставляет пользователей возвращаться каждый день.
*   **💰 Бизнес-мышление (Monetization ready):** Интегрированы UI-паттерны для подписки **ZENKU PRO** (безлимитный ИИ, расширенная статистика).
*   **🛠 Полноценный игровой движок:** Автоматическая генерация уникальных полей разной сложности, система "карандашных" заметок, история ходов (Undo), счетчик ошибок и таймер.

##  Технический стек и Архитектура (MVP)

На этапе хакатона я приняла решение использовать **Vanilla HTML/CSS/JS (Single File Component style)**. Почему?
1. **Скорость итерирования:** Максимальный фокус на UI/UX и проверке продуктовых гипотез (Vibe Coding).
2. **Zero-dependency:** Мгновенная загрузка приложения, отсутствие долгих сборок. 
3. Данные (статистика, стрик) на данном этапе сохраняются в `LocalStorage`.

**Roadmap (План масштабирования):**
*   *Frontend:* Миграция на **Next.js + Tailwind CSS** для более удобного стейт-менеджмента.
*   *Backend:* Интеграция **Supabase** для реализации глобального лидерборда (Daily Challenge) и сохранения прогресса пользователей.
*   *AI:* Подключение реального API (Claude 3 / GPT-4o) для обработки сложных игровых сценариев.
